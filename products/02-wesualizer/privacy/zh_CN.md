# Wesualizer — 隐私政策

最后更新：2026年10月29日

由 BURGESS1977 提供的 Wesualizer 会访问网页和 PDF 内容以及文档 URL，以提供文本分析、摘要、词语高亮及相关功能。分析、AI 摘要和翻译均在您的设备上运行。

我们不会接收、出售或共享此扩展程序处理的文档内容或浏览活动。Wesualizer 不包含广告或分析追踪功能。

分析结果、摘要、URL 和提取的 PDF 文本可能会缓存在浏览器会话存储中。您暂停摘要的文档 URL 会保存在本地。语言和摘要偏好设置使用 Chrome 的同步存储，启用同步后可能通过 Google 进行同步。 文档内容和 URL 不会存储在 Chrome 的同步存储中。

会话缓存在内存中保留，并在 Chrome 重启或扩展程序被停用、重新加载或更新时清除。本地设置及已暂停摘要的文档 URL 保存在设备上，并在卸载扩展程序时删除。您可以随时更改设置、恢复摘要、撤销网站访问权限或移除扩展程序。

Chrome 可能会下载 AI 模型或语言包，PDF 分析可能会从其原始主机获取 PDF。这些浏览器和网站服务受各自隐私政策的约束。

Wesualizer 对从 Google API 获取的信息的使用遵守 Chrome 应用商店用户数据政策，包括其 Limited Use（有限使用）要求。

本政策可能会更新，以反映扩展程序或适用要求的变化。
